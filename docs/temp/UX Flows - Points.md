# User Journeys with UI/UX Flow

## **📌 Earning and Redeeming Green Points**

### **Steps & UX Flow:**

1. **Open App & Daily Check-in**

   * **Welcome Screen:** User opens the app, sees daily check-in prompt.

   * **Action:** Taps "Check-in."

   * **Result:** App awards daily login bonus points, visual "+20 points\!" animation displayed.

2. **Log Sustainable Habit**

   * **Home Dashboard:** Displays button "Log Habit".

   * **Action:** Taps "+ Log Habit", selects habit from predefined list (e.g., biking to work).

   * **Result:** Confirmation animation ("+50 points\! Habit logged"), points total updates instantly.

3. **View Points**

   * **Dashboard:** User sees accumulated points prominently displayed.
