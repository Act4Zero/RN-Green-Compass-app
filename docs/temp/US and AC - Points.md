# User Stories & Acceptance Criteria \- Daily Rewards & Green Points

**User Story:**

* As a user, I want to earn Green Points when logging sustainable habits, completing daily check-ins, and participating in the community so that I stay motivated and engaged.

**Acceptance Criteria:**

* ✅ Users earn predefined Green Points for logging habits.  
* ✅ Users earn bonus points for consecutive daily logins.  
* ✅ Users see visual confirmation of points earned (e.g., "+50 Green Points\!").  
* ✅ Points balance updates immediately after actions.
